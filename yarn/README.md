# Yarn models

| Calculator | Examples | Start here |
|---|---|---|
| Rotating yarn stands | Lemon v05, Peach v13/v14, Pitaya revisions and comparison stands | [Calculator README](stand-simulator/README.md) |

The calculator combines rotational dynamics, support/contact checks, a browser
interface and separate mesh/manufacturing audits. Each saved input or report
identifies its CAD revision and assumptions; a preset is not automatically the
latest printable revision in the [CAD catalog](https://github.com/Griboedow/3d-Models/tree/main/yarn-stands).
